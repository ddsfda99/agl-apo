What the bug is and where it lives
- The reported bug “Failed to create HTML snapshot if URL too long” is due to generating an output filename that includes the entire sanitized URL. This can exceed filesystem filename limits and cause ENAMETOOLONG.
- The offending code is in bookmarks/services/tasks.py in _generate_snapshot_filename(). It returns:
  snapshot_<timestamp>_<sanitized_url>.html.gz
  with no length cap on the sanitized_url portion.

Why it fails at runtime
- For very long URLs, the generated filename itself exceeds the OS limit (commonly 255 bytes for a filename).
- Additionally, singlefile.create_snapshot writes to a temporary path by appending “.tmp” to the final filepath. Even if you cap the final filename at 255 chars, adding “.tmp” makes it longer (e.g., 259), which can still trigger ENAMETOOLONG on the temp file. You must reserve room for the .tmp suffix too.

How to fix the code correctly
Implement a length cap and a hash for long URLs in _generate_snapshot_filename(). Key points:
- Keep the existing sanitization logic.
- Compose prefix and extension separately:
  - prefix = f"{asset.asset_type}_{formatted_datetime}_"
  - ext = ".html.gz"
- Account for the tmp suffix used by singlefile: temp_extra = ".tmp"
- Use a max filename length for the base (before .tmp is added), e.g. max_len = 255 - len(temp_extra) so the temp filename also stays within 255.
- Compute the allowed length for the URL part: max_url_len = max_len - len(prefix) - len(ext)
- If sanitized_url length ≤ max_url_len: use it as-is.
- Else:
  - Compute a stable short hash of the original URL, e.g. hash8 = sha1(url).hexdigest()[:8] (fast, deterministic, avoids collisions).
  - Reserve room for “_” + hash8: reserved = 1 + len(hash8)
  - Truncate sanitized_url to max_url_len - reserved.
  - Build filename: prefix + truncated + "_" + hash8 + ext
- This ensures both the final filename and the temporary filename are within limits.

Concrete example implementation logic (not heavy formatting):
- formatted_datetime = asset.date_created.strftime("%Y-%m-%d_%H%M%S")
- sanitized_url = "".join(char if char.isalnum() or char in "-_." else "_" for char in asset.bookmark.url)
- prefix = f"{asset.asset_type}_{formatted_datetime}_"
- ext = ".html.gz"
- tmp_extra = ".tmp"
- max_len = 255 - len(tmp_extra)
- max_url_len = max_len - len(prefix) - len(ext)
- If len(sanitized_url) <= max_url_len: return prefix + sanitized_url + ext
- Else: hash8 = sha1(asset.bookmark.url.encode("utf-8")).hexdigest()[:8]
  - truncated = sanitized_url[: max_url_len - 1 - len(hash8)]
  - return prefix + truncated + "_" + hash8 + ext
