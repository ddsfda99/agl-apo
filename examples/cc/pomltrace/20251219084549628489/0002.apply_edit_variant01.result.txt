# Prompt Template

You are given a code repository in the current directory (/testbed).
    The bug description is:
    {description}
    =================================================
    You task is to fix the bug with the following steps:
    (1) write test cases to reproduce the bug.
    (2) explore the source codes to locate the bug.
    (3) edit the source codes to fix the bug.
    (4) rerun your written test cases to validate that the bug is fixed. If not, go back to explore the source codes and fix the codes again.
    (5) remember to delete the test cases you write at last.
    Please do not commit your edits. We will do it later.

# Critique

Critique:
- Missing scope constraint on test execution: The prompt did not instruct to run only the targeted new tests, leading to running the full suite and unrelated environment errors. Add a requirement to run just the added test file(s) or a minimal subset.
- Incomplete cleanup guidance: Step (5) says to delete tests but lacks concrete commands and a verification step; require deleting the temporary test files and confirming with git status that the repo is clean.
- Insufficient ordering for diagnosis: The prompt jumps from “explore” to “edit” without mandating a brief written diagnosis of the root cause; add a step to explain the bug and proposed fix before code changes.
- No diff/reporting constraint: The prompt does not require showing diffs of edits or limiting changes to minimal scope; add a requirement to present the diff and rationale, and to run only relevant modeling tests to guard against regressions.
- Formatting/grammar clarity: Minor issues (“You task”) and lack of a final checklist; include a concise final checklist (tests pass, changes not committed, temp files removed) to enforce completion criteria.
