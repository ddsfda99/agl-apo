# Prompt Template

You are given a code repository in the current directory (/testbed).
    The bug description is:
    {description}
    =================================================
    You task is to fix the bug with the following steps:
    (1) write test cases to reproduce the bug.
    (2) explore the source codes to locate the bug.
    (3) edit the source codes to fix the bug.
    (4) rerun your written test cases to validate that the bug is fixed. If not, go back to explore the source codes and fix the codes again.
    (5) remember to delete the test cases you write at last.
    Please do not commit your edits. We will do it later.

# Critique

Critique:

- The prompt does not explicitly instruct the model to verify or re-run tests after code modifications before marking tasks as completed, which may cause premature completion of fix tasks.

- There is no explicit guidance on improving or clarifying error message content in the test assertions, leading to a test that expects the error message to mention the removed column name ('flux'), which the existing code does not produce.

- The prompt omits specifying how to handle or report test failures, including interpreting failure reasons and adjusting code or tests accordingly.

- The iterative loop of exploring, fixing, and validating is mentioned, but no explicit mechanism for adapting the test or fix based on test output is given, potentially causing repeated failures.

- The prompt lacks formatting constraints or explicit instructions for the style or clarity of error messages, which could lead to vague or misleading exception messages being accepted.
