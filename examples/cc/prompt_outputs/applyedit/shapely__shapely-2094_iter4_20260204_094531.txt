Implement the enhancement: **Expose the GEOS WKTReader “fix_structure” option in Shapely’s WKT reader**, so that invalid-but-repairable structures like **unclosed polygon rings** can be loaded when requested.

## Expected behavior
Given a WKT polygon with an unclosed ring:
```python

```

- Current behavior (strict) should remain default:

- New behavior:
  - `shapely.wkt.loads(bad, fix_structure=True)` loads successfully and returns a geometry whose exterior ring is closed (last point equals first).
  - Same option should be available in `shapely.from_wkt(bad, fix_structure=True)` (or whichever internal function `wkt.loads` calls in this codebase).

### API design constraints
- Add **only** the new keyword needed for this task: `fix_structure` (boolean, default `False`).
- Do not introduce additional public parameters like `strict=` or `on_invalid=` unless they already exist in the repo and are necessary for wiring. Keep surface area minimal and aligned with the issue request.
- Ensure backward compatibility: existing calls without `fix_structure` must behave identically.
