Task goal
Enable automatic linkification of plain-text URLs in notes/description so that strings like https://github.com become clickable anchors without requiring Markdown link syntax.

Important constraints
- Do not modify, add, or commit any permanent changes to the existing test suite. If you need a reproduction test, create it temporarily for local validation and delete it before finishing.

What to implement
- Plain URLs in user-entered notes/description should be clickable in rendered HTML even when not wrapped in Markdown link syntax.
- Do not linkify inside inline code or code blocks.
- Implement this within the markdown rendering pipeline used for notes/description, preserving the existing sanitization and security model.

Process and steps

1) Understand and plan
- The feature belongs in the markdown parsing/rendering stage used for notes/description. It should require no template changes.
- The correct processing order is: convert markdown to HTML, then linkify plain URLs, then sanitize the HTML.
- Linkification must not occur inside a, code, or pre tags.

2) Locate the markdown rendering code
- Search within the project’s own code (avoid node_modules and vendored directories). Likely location: bookmarks/templatetags/shared.py.
- Find the function/filter that converts notes/description from markdown to sanitized HTML (often named render_markdown or similar).
- Identify the allowlists used for sanitization, e.g., variables like markdown_tags and markdown_attrs, and confirm the project uses bleach.clean for sanitization.

3) Verify allowlists and minimally adjust if necessary
- Ensure the allowed tags include the anchor tag: a.
- Ensure the allowed attributes include href for a. Use the project’s existing allowlist structure; only add a and href if they are currently missing.
- Do not broaden the allowlist beyond what is required to preserve security and current behavior.

4) Implement linkification with minimal changes
- After markdown conversion to HTML and before sanitization, call bleach.linkify on the HTML.
- Explicitly set skip_tags to ['a', 'code', 'pre'] to avoid linkifying inside existing anchors or code/pre blocks.
- Then sanitize the output with bleach.clean using the existing tag and attribute allowlists.
- Do not introduce target attributes or modify rel attributes. If bleach.linkify adds rel attributes by default and they are not allowed, bleach.clean will strip them; that is acceptable.
- Add a brief code comment explaining the processing order and why skip_tags includes a, code, and pre.

Implementation outline
- In the markdown rendering function:
  - Convert the input markdown to HTML as currently done.
  - Apply bleach.linkify(html, skip_tags=['a', 'code', 'pre']).
  - Sanitize with bleach.clean(html, tags=markdown_tags, attributes=markdown_attrs).
