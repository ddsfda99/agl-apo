## Task

Chrome is rolling out third-party cookie restrictions; cookies intended for third-party contexts may require the `Partitioned` attribute (CHIPS). CPython is adding support in 3.13, but Falcon can’t rely on stdlib behavior alone because Falcon generates cookie headers itself.

   Therefore: **apply `partitioned` only after SameSite has been normalized and written to the morsel**, near the end of `set_cookie()` after all other attribute assignments that might mutate/reset reserved/flag attributes.

## Requirements
1. `Response.set_cookie()` must accept a new kwarg: `partitioned` (boolean or None).
   - If `partitioned=True`, emit the `Partitioned` attribute in the `Set-Cookie` header for that cookie.
   - If `partitioned=False`, do not emit it.
   - If `partitioned is None`, preserve existing behavior unless requirement (2) applies.

2. Automatic behavior (only if required by the codebase’s expectations/tests):
   - If `partitioned is None` and the cookie is being set with `same_site='None'` (case-insensitive), then automatically enable Partitioned (equivalent to `partitioned=True`).
   - This auto-enable decision must be based on the **normalized/validated** `same_site` value (after Falcon’s existing lowercasing/validation/capitalization logic), not the raw user input.
   - Do not invent other auto-rules (e.g., requiring Secure) unless Falcon already enforces them; tests should set `secure=True` when `same_site='None'`.

3. Backport/compatibility approach:
   - Falcon may already backport cookie attributes by updating `http.cookies.Morsel._reserved` (e.g., `SameSite`). Follow that style.
   - Keep any stdlib patching minimal and consistent with existing Falcon approach. Avoid new hacks.

4. Tests:
   - Add a focused regression test that fails on current main and passes after your fix.
   - The test must assert that the generated cookie includes `Partitioned` when expected.
   - Prefer using existing cookie testing patterns (likely `result.cookies[...]`) rather than `result.headers['set-cookie']`.
   - Do not “fix” by teaching the test client to guess Partitioned; the source of truth is Falcon’s generated cookie output.
