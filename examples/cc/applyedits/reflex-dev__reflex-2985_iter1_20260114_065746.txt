Goal
Implement tuple-return normalization for page functions so that returning a tuple of Components becomes a single valid Component (a Fragment), and add robust tests that verify both plain and decorated page functions. Run tests even if pytest or rich are unavailable, and delete any test files before finishing. Do not commit any edits.

Context and key guidance
- Normalize page return values in App._generate_component (reflex/app.py). That function already converts either a Component or a callable that returns a Component. If the callable returns a tuple, wrap it with Fragment.create(*result). Keep the fix localized to _generate_component; do not overhaul add_page.
- Tests must not rely on tag names or theme-dependent strings. Assert by type, structure, and child count. It’s fine to assert isinstance checks, and that a Fragment exists with exactly two children in the correct order. Avoid assertions like “Text” vs “P”.
- Cover both cases:
  - app.add_page(page_func_returning_tuple)
  - a @rx.page-decorated function returning a tuple passed to app.add_page (ensure decorated functions go through the same normalization path).
- The repo environment may lack pytest and rich. If pytest is unavailable, run tests by directly importing and calling the test functions. To avoid rich import issues when importing reflex, stub the rich module in sys.modules before importing/reflex indirectly. Also, do not import the tests package to avoid triggering tests/__init__.py; instead load the test module by file path via importlib.util.
- Delete the test files you add at the end. Do not commit any edits.

    - Build a minimal app: app = rx.App()
    - Define a page function returning a tuple:
      def index():
          return rx.text("Hello"), rx.text("World")
    - Add the page: app.add_page(index, route="/")
    - Retrieve the page component from app.pages by the route key "/" (or directly by value if you prefer).
    - Assert structural properties:
      - The stored page component is a Fragment or a subclass of Fragment (the app may wrap pages in an OverlayFragment which subclasses Fragment).
      - There exists a Fragment-like child that has exactly two children, corresponding to the tuple elements, in order.
      - Both children are Components (isinstance checks).

  - test_decorated_page_returns_tuple_unwrapped_to_fragment()

      @rx.page()
      def decorated_index():
          return rx.text("Hi"), rx.text("There")
    - Add it to the app: app.add_page(decorated_index)
    - Compute the route key using reflex.utils.format.format_route(decorated_index.__name__) to avoid mismatches; do not hard-code.
    - Retrieve the page component, and assert the same structural properties as above.

  - For the decorated test, import format_route: from reflex.utils.format import format_route

  - If the page_component has a nested structure (e.g., an overlay-like wrapper), iterate its children to find a Fragment child (isinstance(child, Fragment)). Then examine that child’s children sequence.
