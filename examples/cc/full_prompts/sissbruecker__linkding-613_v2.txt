Bug description: Support disabling alphabetical grouping in tag cloud
Different from the alphabetical characters, the Chinese characters are diverse and will result in one line, one tag. 
It would be nice to have an option to disable the line break between groups.

Currently I use the Stylus for a workaround:

```css
.tag-cloud .group {
  display: inline;
}
```



Goal
- Add an option to disable alphabetical group line breaks in the tag cloud. When the preference is enabled, render tag groups inline so there aren’t separate lines for each group (especially for languages like Chinese). Preserve current behavior by default.

Repository context and likely code locations to inspect
- Template that renders the tag cloud: bookmarks/templates/bookmarks/tag_cloud.html. It currently renders each tag group as a paragraph element p with class "group", which creates line breaks.
- Tag groups and context building: bookmarks/views/partials/contexts.py, specifically TagGroup.create_tag_groups and TagCloudContext.
- User preferences: UserProfile.search_preferences. Preferences are injected into search defaults and passed to templates via the context. Today templates can access tag_cloud.search.defaults, but prefer adding an explicit context flag to decouple the template from BookmarkSearch internals.
