PR description: RPM packaging for OpenSUSE fails to move package to `dist` directory
### Describe the bug

Packaging an RPM for OpenSUSE fails when Briefcase attempts to move the package to the `dist` directory.

```
FileNotFoundError: [Errno 2] No such file or directory: '/home/russell/tmp/beeware/helloworld/build/helloworld/opensuse-tumbleweed/20240109/rpmbuild/RPMS/x86_64/helloworld-0.0.1-1.el20240109.x86_64.rpm'
```

### Steps to reproduce

`briefcase package linux system --target opensuse/tumbleweed`

### Expected behavior

The RPM package is properly moved to the `dist` directory.

The RPM is called `helloworld-0.0.1-1.x86_64.rpm`; not `helloworld-0.0.1-1.el20240109.x86_64.rpm`. OpenSUSE appears to be leaving off the distro tag.
